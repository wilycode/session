# Changelog

All notable changes to WilyCode Session are documented here.

## [0.1.0] - 2026-10-12

### Added

- First public release of the storage-agnostic `SessionInterface` contract.
- Namespace-scoped access to session values.
- Interfaces for reading, writing, removing, replacing, listing, and clearing session data.
- README examples, contract tests, and GitHub Actions configuration.
